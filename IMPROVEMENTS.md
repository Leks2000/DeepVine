# Улучшения проекта DeepVine

## Уже исправлено в этом проходе

- Сделать нижние палубы физически доступными: добавлены явные интерактивные точки спуска/подъёма, подсветка маршрутов, визуальные маяки и безопасные координаты телепорта.
- Уточнить геометрию нижнего торпедного и нижнего машинного отсеков: потолочные балки, решётчатый пол, боковые трубы, шпангоуты, люковые рамки и читаемые таблички.
- Исправить контроллер игрока для нижних палуб: нижние зоны больше не воспринимаются как временная шахта, игрок удерживается в безопасном коридоре, расчёт коллизий учитывает нижнюю высоту глаз.
- Исправить определение текущего отсека для нижнего машинного уровня, чтобы HUD/логика не называли его обычным верхним машинным отсеком.
- Улучшить визуал подлодки снаружи: добавлен внешний цилиндрический силуэт корпуса, носовой/кормовой обтекатель, рубка, кормовой руль и горизонтальные стабилизаторы.

## Критичные улучшения, которые нужно реализовать дальше

### Навигация и управление игроком

- Добавить полноценную систему лестниц без телепорта: движение по наклонной, анимация подъёма/спуска, блокировка бега на трапах.
- Сделать капсульный контроллер игрока вместо текущих AABB-проверок, чтобы не цепляться за тонкие трубы и панели.
- Добавить crouch/наклон головы для низких отсеков.
- Ввести debug-overlay коллизий для быстрой проверки стен, люков, панелей и нижних палуб.
- Добавить autosave позиции игрока и состояния корабля.

### Геометрия и визуал отсеков

- Разделить геометрию на модульные фабрики: `buildBridge`, `buildTorpedoDeck`, `buildReactorRoom`, `buildEngineRoom`, `buildAirlock`.
- Заменить простые box/cylinder-меши на GLTF-модели для ключевого реквизита: штурвал, дизель, реактор, торпедные аппараты, клапаны, насосы.
- Добавить нормальные двери/гермолюки между отсеками с анимацией и состояниями блокировки.
- Улучшить освещение: baked-like локальные лампы, аварийный красный режим, мерцание при повреждениях, отдельный свет нижних палуб.
- Добавить декали: грязь, ржавчина, номера отсеков, предупреждающие полосы, следы воды.
- Добавить видимые торпедные трубы и механизмы перезарядки в нижнем торпедном отсеке.
- Добавить дизель-генератор, валы, редуктор и аккумуляторные стойки в нижнем машинном отсеке.

### Подлодка снаружи

- Создать отдельную внешнюю модель субмарины с корректным масштабом относительно интерьера.
- Добавить винты, рули глубины, якорные элементы, рубку с перископом и поручнями.
- Связать внешний визуал с состоянием: прожектор, пузырьки, повреждения корпуса, затопление, работа винта.
- Добавить режим внешней камеры/дрона для осмотра корпуса и установки модулей.

### Логика двигателя и управления кораблём

- Оформить запуск двигателя как чеклист с UI-подсказками: рубильник → шина → топливо → масло → подогрев → старт.
- Сделать отдельные состояния дизеля, электромотора и реактора, чтобы ход зависел от выбранной силовой установки.
- Добавить инерцию: разгон, торможение, лаг рулей, лаг погружения/всплытия.
- Сделать систему повреждений двигателя: перегрев, потеря масла, отказ стартера, аварийная остановка.
- Добавить понятный мостиковый дубликат управления, но оставить полную процедуру запуска в нижнем машинном отсеке.

### Игровой цикл

- Добавить цели миссии: исследование POI, сбор ресурсов, ремонт, эвакуация, возвращение на поверхность.
- Добавить журнал задач и карту/сонарную навигацию.
- Добавить туториал первого запуска подлодки.
- Сделать экономику апгрейдов: батарея, насос, корпус, сонар, двигатель, торпеды, кислород.
- Добавить угрозы: давление, мины, хищники/дроны, течи, пожары, отказ электроники.

### Архитектура и качество

- Перевести JS-модули на TypeScript полностью и включить строгую проверку типов.
- Добавить unit-тесты для `sim`, контроллера и интерактивных сценариев.
- Добавить Playwright smoke-test: загрузка страницы, старт игры, спуск в нижний отсек, запуск двигателя.
- Вынести настройки баланса в JSON/TS-конфиг.
- Добавить CI: install, lint, typecheck, build, smoke.
- Добавить README с управлением, процедурой запуска, картой отсеков и troubleshooting.
